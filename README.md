## 這是什麼？

一個純網頁工具。你從 Instagram 匯出自己的追蹤資料（JSON），丟進網頁，幾秒內就能看到：

| 分頁 | 說明 |
|---|---|
| 對方未回追 | 你追蹤他，但他沒追蹤你 |
| 我未回追 | 他追蹤你，但你沒追蹤他 |
| 互相追蹤 | 彼此都有追蹤 |
| 流失追蹤者 | 與上次分析比對，誰不再追蹤你 |
| 新增追蹤者 | 與上次分析比對，誰新追蹤了你 |
| 已取消追蹤 | Instagram 官方記錄的、你最近取消追蹤的帳號 |
| 待處理請求 | 你送出、對方還沒接受的追蹤請求 |
| 已忽略 | 你按過「忽略」的帳號（例如故意追蹤的名人、品牌），可隨時還原 |

另外有搜尋功能，點任一帳號可直接開啟對方的 Instagram 主頁。想先看看效果，可以按頁面上的「**先用範例資料試玩**」。

### 更多功能

- **忽略名單**：常追蹤名人或品牌？按帳號右邊的「忽略」，就會從清單和統計中隱藏
- **排序**：依日期（新到舊、舊到新）或帳號名稱排序
- **匯出**：一鍵複製目前的清單，或下載 CSV（Excel、Google 試算表都能開）
- **歷史紀錄備份與匯入**：換手機或電腦時，把上次的紀錄帶過去，繼續比對誰退追
- **清除資料**：想換分析另一個帳號時，一鍵清除已儲存的紀錄；上傳時若發現和上次的帳號差異很大，也會主動詢問

## 為什麼值得用？

- 🔒 **隱私優先**：匯出檔只在你的瀏覽器中處理，**不會上傳到任何伺服器**
- 🚫 **不需要密碼**：完全不用登入 Instagram，沒有封號風險
- ⚡ **快速**：拖進 zip（不用解壓縮），幾秒鐘就出結果
- 📖 **有詳細的使用說明**：網頁內附逐步教學，不熟悉匯出流程也能上手

## 怎麼使用？

1. 在 Instagram：**設定 → 帳號中心 → 你的資訊和權限 → 匯出你的資訊 → 選擇帳號**
2. 只勾選「**追蹤者與追蹤中**」，日期範圍選「**所有時間**」，格式選「**JSON**」
3. 等待通知（通常數分鐘至數小時，最久約 1–2 天），下載 `.zip`（4 天內有效）。**iPhone 請不要點開 zip**，否則會被自動解壓縮
4. 打開 [網頁](https://ig-follow-checker-five.vercel.app/)，把 `.zip` 直接拖進去（如果 Mac 的 Safari 已自動解壓縮，也可以直接拖整個資料夾，或按「選擇資料夾」）

> 想看「誰退追我」？隔一段時間再匯出一次、重新上傳，工具會與上次的紀錄比對。
> 歷史紀錄存在你目前使用的瀏覽器中。換裝置前請先在結果頁按「下載歷史紀錄」，到新裝置再於上傳框下方「匯入」；清除網站資料也會讓紀錄消失，建議定期備份。

匯出檔與歷史紀錄都只存在你自己的裝置，詳見網站的[隱私權說明](https://ig-follow-checker-five.vercel.app/privacy.html)。歷史紀錄檔等同於你的追蹤者名單，請妥善保管，不要隨意公開分享。
