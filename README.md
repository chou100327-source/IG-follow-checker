## 這是什麼？

一個純網頁工具。你從 Instagram 匯出自己的追蹤資料（JSON），丟進網頁，幾秒內就能看到：

| 分頁 | 說明 |
|---|---|
| 對方未回追 | 你追蹤他，但他沒追蹤你 |
| 我未回追 | 他追蹤你，但你沒追蹤他 |
| 互相追蹤 | 彼此都有追蹤 |
| 流失追蹤者 | 與上次分析比對，誰不再追蹤你 |
| 新增追蹤者 | 與上次分析比對，誰新追蹤了你 |
| 已取消追蹤 | Instagram 官方記錄的、你最近取消追蹤的帳號 |
| 待處理請求 | 你送出、對方還沒接受的追蹤請求 |

另外有搜尋功能，點任一帳號可直接開啟對方的 Instagram 主頁。想先看看效果，可以按頁面上的「**先用範例資料試玩**」。

## 為什麼值得用？

- 🔒 **隱私優先**：匯出檔只在你的瀏覽器中處理，**不會上傳到任何伺服器**
- 🚫 **不需要密碼**：完全不用登入 Instagram，沒有封號風險
- ⚡ **快速**：拖進 zip（不用解壓縮），幾秒鐘就出結果
- 🎨 **介面順手**：Instagram 風格的漸層與動畫，支援手機與電腦，自動深色模式
- 📖 **有詳細的使用說明**：網頁內附逐步教學，不熟悉匯出流程也能上手

## 怎麼使用？

1. 在 Instagram：**設定 → 帳號中心 → 你的資訊和權限 → 匯出你的資訊 → 選擇帳號**
2. 只勾選「**追蹤者與追蹤中**」，日期範圍選「**所有時間**」，格式選「**JSON**」
3. 等待通知（通常數分鐘至數小時，最久約 1–2 天），下載 `.zip`（4 天內有效）
4. 打開 [網頁](https://ig-follow-checker-five.vercel.app/)，把 `.zip` 直接拖進去

> 想看「誰退追我」？隔一段時間再匯出一次、重新上傳，工具會與上次的紀錄比對。
> 歷史紀錄存在你目前使用的瀏覽器中，換裝置或清除網站資料就會消失。

## 技術

純 HTML / CSS / JavaScript，不需要後端與建置流程。使用 [JSZip](https://stuk.github.io/jszip/) 讀取 zip，部署在 Vercel。

## 注意事項

本工具為獨立開發，與 Instagram 及 Meta 無關。請只分析**你自己帳號**的匯出資料。
